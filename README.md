# ✈️ フライト計器パネル（シックスパック）

小型機のコックピットにある6つの基本計器「シックスパック」をブラウザで再現した静的Webサイトです。
スマホやタブレットのジャイロ・加速度・方位センサーを使って、**端末を傾けたり回したりすると計器が実際に動きます。**

**▶ 公開ページ: https://kosetei.github.io/flight-instruments/**

## 計器

| 計器 | 動き方 |
|---|---|
| 速度計 (ASI) | スロットルと機首の上げ下げで加速・減速（簡易シミュレーション。アナログは小型機、グラスは旅客機モデル） |
| 姿勢指示器 (AI) | 端末のピッチ（前後の傾き）とロール（左右の傾き）をそのまま表示 |
| 高度計 (ALT) | 昇降率を積分して高度が変化（100ft / 1,000ft / 10,000ft 針） |
| 旋回計 (TC) | ジャイロの回転速度（ヨー）で飛行機マークが傾く。標準旋回（3°/秒）で L/R マーク。ボールは横方向の加速度で動く |
| 方位指示器 (HI) | 端末のコンパス方位（iOSは `webkitCompassHeading`、Androidは `deviceorientationabsolute`） |
| 昇降計 (VSI) | ピッチと速度から昇降率を計算（±2,000 ft/min） |

## 使い方

### スマホ・タブレット
1. 上のURLを開き「📱 センサーを有効にする」をタップします（iPhone/iPadでは許可ダイアログで「許可」）。
2. 有効にした瞬間の構え方が「水平」の基準になります。いつでも「⊕ 水平を校正」で基準をやり直せます。
3. 手前に起こす＝機首上げ、奥に倒す＝機首下げ、ハンドルのように回す＝バンク。体ごと向きを変えると方位計と旋回計が動きます。
4. 画面右端のスロットルレバーを上下にドラッグして推力を変えられます（0〜100%）。グラス表示では N1（エンジン回転）も表示されます。設定（？ → ⚙️）の「スロットル表示」でレバーを隠せます（Pages でも MSFS 連携時でも共通。値はそのまま残り、キーでは操作できます）。
5. 縦向き・横向きどちらでも使えます（画面回転に合わせて軸を補正します）。

> **注意:** モーションセンサーは **HTTPS** でのみ利用できます（GitHub Pages は HTTPS なのでそのまま使えます）。
> ローカルで試す場合は `localhost` か HTTPS で配信してください。`file://` やHTTPではセンサーが動きません。
> iOS で一度「許可しない」を選んだ場合は、Safari を完全に終了して開き直してください。

### 動きの向きがおかしいとき（iPad など）
「？」ボタン →「⚙️ 設定」で調整できます（設定は端末に保存されます）。
- **軸の補正**: 左右に傾けるとピッチが動く（軸が入れ替わる）ときは「+90°」か「+270°」、上下左右とも逆なら「+180°」。
- **上下反転／左右反転**: 片方だけ逆のときに。
- **デバッグ表示**: センサーの生の値（α/β/γ）、`window.orientation`、`screen.orientation`、使っている画面角度などを画面に表示します。URL に `?debug` を付けて開いても表示されます。うまく動かないときはこの画面のスクショを送ってください。
- 画面を回転させると自動で水平の基準を取り直します。

### 📡 GPSモード（実測値で表示）
スタート画面の「📡 GPSも使う」にチェックを入れるか、下のバーの「📡 GPS」ボタンをタップすると、位置情報の許可を求めたあと GPS の実測値で計器が動きます。

| 計器 | GPSモードでの表示 |
|---|---|
| 速度計 | **対地速度（GS）**。`coords.speed` を使用し、取得できない端末では位置の変化から計算。文字盤に「GROUND SPEED」と数値窓（GS 123）を表示（針は200ktまで、それ以上は数値窓で） |
| 高度計 | GPS高度（m→ft、ノイズを平滑化）。端末がGPS高度を返さない場合はシミュレーションのまま「SIM（GPS高度なし）」と表示 |
| 昇降計 | 平滑化したGPS高度の変化から算出（ft/min）。GPS高度のノイズを抑えるフィルター付き |
| 方位指示器 | 約3kt以上で移動中は **GPS航跡（GPS TRK）**、止まっているときはコンパス（COMPASS）。文字盤に表示元を表示 |
| 姿勢指示器・旋回計 | これまでどおりジャイロで動作 |

- GPS で対地速度が取れている間は、設定に関係なくスロットルレバーを隠して計器を広く表示します（約2秒の余裕を見てから出し入れし、測位がちらついてもレイアウトが跳ねないようにしています）。GPS を止めるか速度が途切れると、設定が「表示」ならレバーは元の位置のまま再表示されます。
- 画面左上に GPS の精度（±m）、測位状態、各値が実測（GPS）かシミュレーション（SIM）かを表示します。
- **屋外・車や電車・飛行機の中**で使うと楽しいです。飛行機では**窓側の席**ならスマホのGPSでも測位できることが多く、実際の対地速度・高度・昇降率が見られます（機内モードでもGPSは動作します。航空会社の指示に従ってください）。
- 屋内やビルの谷間では測位できなかったり、高度・速度が大きくぶれることがあります。GPS高度は一般に水平位置より誤差が大きいです。
- 位置情報も **HTTPS** が必要です。許可しなかった場合は端末/ブラウザの設定から位置情報を許可してください。
- 位置情報は端末内で計器表示に使うだけで、どこにも送信・保存しません。

### 🖥 グラスコックピット表示（旅客機風）
下のバーの「▭ グラス」ボタンで、旅客機のような液晶計器（PFD と ND）に切り替えられます（「◎ アナログ」で元に戻ります）。
選んだ表示は次回も記憶され、URL の末尾に `#glass` / `#analog` を付けて直接開くこともできます。
例: https://kosetei.github.io/flight-instruments/#glass

**PFD（主飛行表示）**
- 大きな姿勢表示（空色／茶色、ピッチラダー、バンク角スケールと指針、横滑りを示す台形マーク、機体シンボル、緑の飛行経路マーカー）
- 左：速度テープ（〜500kt、10秒後の速度を示すトレンド矢印、下の一桁が回転する数字窓）。GPSモードでは「GS」表示
- 右：高度テープ（〜45,000ft、下2桁が20ft刻みで回転する数字窓）と昇降率スケール（±6,000ft/min、数値表示つき）
- 下：方位コンパス（旋回率から10秒後の方位を示す緑の弧、GPS航跡マーカー）
- 上：モード表示帯（速度・高度・方位・姿勢・GPSの各データが GPS／COMPASS／SIM などどこから来ているかを緑・琥珀・白で表示）

**ND（航法表示）**
- 機首方位が上のアーク表示、方位コンパス、距離リング、対地速度（GS）・TAS 表示
- GPS（またはシミュレーション）の **飛行の軌跡（シアンの線）**、スタート地点（マゼンタ）とそこからの距離、旋回率から予測した90秒先までの進路（白の破線）
- 右下の「RANGE」をタップすると表示範囲を切り替え（AUTO → 0.5 → … → 320 NM）

横向きでは PFD と ND が左右に、縦向きでは上下に並びます。アナログの6連計器は 200kt・±2,000ft/min までですが、グラス表示なら旅客機の巡航（GPSで 450kt 以上・3万ft 以上）もそのまま表示できます。

シミュレーション時の速度モデルは表示モードで切り替わります（切り替えても値は飛び跳ねず、徐々に新しいモデルへなじみます）。
- **アナログ（小型機）**: アイドルで約55kt、通常スロットル（70%）で約110kt、全開で約155kt。昇降はおおむね ±1,000ft/min 前後。
- **グラス（旅客機）**: アイドルで約130kt、進入相当（約45%）で約180kt、巡航（約75%）で約280kt、全開で約330kt。慣性は大きく、加速・減速はゆっくり。昇降は数千ft/minまで。旋回率は速度が速いほど緩やかになります。
- グラスの PFD 左下に **N1**（推力レバーから換算したエンジン回転の目安）を表示します。

### パソコン（ジャイロなし）
- 「▶ デモを見る」で自動飛行デモ。
- 計器パネルを **ドラッグ**（左右＝バンク、上下＝ピッチ）、または **矢印キー** で操縦できます。
- 右端のスロットルはドラッグのほか、`PageUp` / `PageDown` または `+` / `−`（ホイールも可）で操作できます。
- `Space` で水平に戻す、`D` でデモに戻ります。

## 更新が反映されないとき
GitHub Pages はファイルを最大10分キャッシュします。ページは起動時に `version.json` を確認し、古い版を開いていたら自動で1回だけ読み込み直します。
今のバージョンは「？」画面の下とデバッグ表示（`?debug`）の1行目に出ます。それでも古いままなら、タブを閉じて開き直すか URL に `?v=適当な文字` を付けて開いてください。
（開発者向け: 公開前に `./bump-version.sh` を実行すると、バージョン番号が `app.js`・`index.html` の `?v=`・`version.json` に書き込まれます）

## MSFS 2020 と連携する（LAN ブリッジ）

Windows 上の Microsoft Flight Simulator 2020 の計器値を、同じ Wi-Fi の iPad / スマホに送れます。やり方は [`msfs-bridge/README.md`](msfs-bridge/README.md) にあります（`start.bat` を実行し、表示された URL を iPad で開くだけです）。

GitHub Pages の公開ページ（ジャイロ／GPS 用）の動きは変わりません。MSFS 連携はブリッジ経由の URL を開いたときだけ有効です。

## ローカルで動かす

ビルド不要・外部ライブラリなしの HTML/CSS/JavaScript だけで出来ています（MSFS 連携を使う場合だけ Node.js が必要です）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## ファイル構成

- `index.html` … ページ本体
- `style.css` … ダークなコックピット風デザイン、縦横レスポンシブ
- `glass.js` … グラスコックピット表示（PFD／ND）
- `app.js` … SVG計器の描画、センサー処理（平滑化・校正・画面回転補正）、GPS処理、スロットル、簡易フライトモデル（小型機／旅客機）、MSFS ブリッジ接続
- `msfs-bridge/` … MSFS 2020 用 SimConnect ブリッジ（LAN 配信 + WebSocket）

※ 計器の動きは雰囲気を楽しむためのもので、実際の航法には使えません。
